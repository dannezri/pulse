# 📝 Changelog - Prompt Système Gemini

## Version 1.1 - 2026-02-03

### ✅ Changements Majeurs

Le prompt système de Gemini a été **complètement réécrit** pour utiliser des analogies ultra-pédagogiques et un ton plus empathique.

---

## 🎯 Nouveautés

### 1. Les 3 Analogies Obligatoires

Le prompt impose maintenant **3 analogies spécifiques** pour réduire la charge mentale :

#### 🔌 Le Câblage (HRV)
- **Avant** : "Ton HRV est bas, ton système nerveux ne récupère pas"
- **Après** : "Ton câblage nerveux est endommagé. C'est comme charger ton téléphone avec un câble USB effiloché : l'électricité ne passe plus."

#### ⛽ Le Réservoir (Sommeil)
- **Avant** : "Tu as une dette de sommeil qui affecte ta récupération"
- **Après** : "Ton réservoir fuit en permanence. Tu dors 6h mais ton corps en a besoin de 8h : c'est 2h de carburant qui s'évaporent chaque nuit."

#### 🚦 Le Limiteur de Vitesse (Chimie)
- **Avant** : "Tes médicaments ont un impact sédatif"
- **Après** : "Tu as un pied sur l'accélérateur (Sertraline) et l'autre sur le frein (Mirtazapine). Ton moteur veut avancer mais le limiteur de vitesse est activé."

---

### 2. Structure Obligatoire (4 Cartes)

Le prompt impose maintenant une structure narrative :

| Carte | Type | Focus | Analogie |
|-------|------|-------|----------|
| **1. Le Diagnostic** | nervous | HRV ↔ Récupération | 🔌 Câblage |
| **2. Le Paradoxe** | chemistry | Boosters vs Freins | 🚦 Limiteur |
| **3. La Charge Invisible** | load | Pathologies | 🎒 Sac à dos |
| **4. Conseils** | activity | 3 micro-actions | ⚡ Actions |

---

### 3. Ton Empathique Renforcé

**Avant** :
```
"Ton énergie est basse à cause de ton HRV et de ta dette de sommeil."
```

**Après** :
```
"Ton câblage nerveux est endommagé (HRV 25ms vs 50ms baseline). 
Même avec du repos, l'énergie ne circule plus correctement. 

💚 Ton corps fait de son mieux avec les ressources disponibles. 
C'est déjà énorme."
```

**Changements clés** :
- ✅ Validation de la fatigue comme réalité biologique
- ✅ Jamais culpabilisant
- ✅ Encouragement systématique en fin de message
- ✅ Emojis pour la lisibilité

---

### 4. Focus Pharmacocinétique

Le prompt est maintenant **expert en pharmacocinétique** :

**Avant** :
```
"Tes médicaments ont un impact sur ton énergie."
```

**Après** :
```
"Tu prends Sertraline (+15% énergie) mais aussi Mirtazapine (-25% sédation). 
Ces deux médicaments se battent : l'un veut accélérer, l'autre ralentir. 
Résultat net : -10% d'énergie disponible.

🚦 C'est comme conduire avec un pied sur l'accélérateur et l'autre sur le frein."
```

**Nouveautés** :
- ✅ Nomme les médicaments spécifiques
- ✅ Cite les impacts calculés (+15%, -25%)
- ✅ Explique les interactions (boosters vs freins)
- ✅ Calcule l'impact net

---

### 5. Charges Invisibles

Le prompt identifie maintenant les **coûts métaboliques cachés** :

**Avant** :
```
"Tes conditions de santé affectent ton énergie."
```

**Après** :
```
"Ta sinusite chronique force ton corps à dépenser de l'énergie juste 
pour compenser la mauvaise oxygénation. C'est un coût métabolique 
permanent que tu ne vois pas mais qui épuise tes réserves.

🎒 C'est comme porter un sac à dos de 10kg toute la journée sans 
t'en rendre compte."
```

**Nouveautés** :
- ✅ Explique le mécanisme physiologique
- ✅ Quantifie l'impact (-15%)
- ✅ Utilise l'analogie du sac à dos invisible

---

### 6. Conseils Actionnables

Le prompt génère maintenant des **micro-actions concrètes** :

**Avant** :
```
"Essaie de mieux dormir et de gérer ton stress."
```

**Après** :
```
⚡ 3 micro-actions aujourd'hui :

1. 🌬️ 5 min de respiration nasale (sinus)
2. ☀️ 15 min de lumière naturelle (médicaments)
3. 💤 Sieste de 20 min max (dette sommeil)

Chaque micro-action compte. Commence par une seule aujourd'hui. 💚
```

**Nouveautés** :
- ✅ Actions mesurables (5 min, 15 min, 20 min)
- ✅ Basées sur les anomalies détectées
- ✅ Réalisables dans la journée
- ✅ Encouragement bienveillant

## 📊 Comparaison Avant/Après

### Exemple Complet

**Données** :
- Énergie : 34%
- HRV : 25ms (baseline: 50ms)
- Sommeil : 6h (besoin: 8h)
- Médicaments : Sertraline (+15%), Mirtazapine (-25%)
- Conditions : Dépression, Sinus

#### Version 1.0 (Avant)

```
💡 Pourquoi ce score ?

Votre énergie est basse à 34%. Votre HRV est à 25ms (baseline: 50ms), 
ce qui indique une récupération insuffisante. Vous avez une dette de 
sommeil de 2h. Vos médicaments ont un impact sédatif.
```

#### Version 1.1 (Après)

```
💡 Pourquoi ce score ?

🔌 Le câblage est défaillant

Ton HRV est à 25ms (baseline: 50ms). Ton système nerveux parasympathique 
ne transmet plus l'énergie efficacement, même après 6h de sommeil.

💡 C'est comme charger ton téléphone avec un câble USB sectionné : 
l'électricité ne passe plus.

---

🚦 Accélérateur ET frein activés

Tu prends Sertraline (+15%) mais aussi Mirtazapine (-25%). Ces deux 
médicaments se battent. Résultat net : -10% d'énergie disponible.

💡 C'est comme conduire avec un pied sur l'accélérateur et l'autre 
sur le frein.

---

⚡ 3 micro-actions aujourd'hui

1. 🌬️ 5 min de respiration nasale (sinus)
2. ☀️ 15 min de lumière naturelle (médicaments)
3. 💤 Sieste de 20 min max (dette sommeil)

💚 Ton corps fait de son mieux avec les ressources disponibles. 
C'est déjà énorme.
```
